### 🔄 Como Alternar o Tema Ativo

Para ativar qualquer um dos temas:

1. Abra o arquivo do tema desejado dentro da pasta `themes/` (ex: `themes/README_CYBER_EMERALD.md`).
2. Copie todo o conteúdo do arquivo.
3. Cole e salve no arquivo principal [`README.md`](../README.md).
4. Faça o commit e push para o GitHub:
   ```bash
   git add README.md
   git commit -m "style: update profile theme"
   git push origin main
   ```
